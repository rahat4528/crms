# Virga — Considered Fashion & Living

> **Brand Identity:** Premium, minimal, elegant, modern, and editorial e-commerce platform curated for timeless fashion and refined living.

Virga is an enterprise-grade full-stack e-commerce application built with Next.js 15 (App Router), React 19, TypeScript (Strict), TailwindCSS v4, Mongoose / MongoDB, and Auth.js v5.

## Quick Start

```bash
cd modo-web
pnpm install
pnpm dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the customer storefront or [http://localhost:3000/studio](http://localhost:3000/studio) to access Virga Studio.

For full architectural documentation, environment configuration, and test suites, see [`modo-web/README.md`](modo-web/README.md).
